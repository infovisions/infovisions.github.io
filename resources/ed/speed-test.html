Rapid user testing: does your color say the right speed?

Your group gets its own set of eight speed limits, and each tester sees them in a different random order. Nobody can guess their way through by learning the answers.

Set up your test

Your class code and group name determine which speeds you test — the list below changes as you type. Settle on a name before you build your signs.

Run the test

1Turn your screen away from the person you're testing — they should see your colored sign, never the number.
2Show the signs in the order below. Ask "what speed limit is this?" and type what they say.
3No hints, no corrections, no reactions between guesses, and don't tell them the answers when you're done — they may be testing for another group next.
